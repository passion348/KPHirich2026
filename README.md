# Pro Logic — Десктопна система управління вантажоперевезеннями та логістикою

Курсовий проєкт розроблений в рамках навчання у Полтавському політехнічному фаховому коледжі (спеціальність 121 «Інженерія програмного забезпечення»).

## Технологічний стек
* **Платформа:** .NET (WPF / XAML)
* **Мова програмування:** C#
* **База даних:** SQLite
* **ORM:** Entity Framework Core
* **UI/UX Бібліотека:** MaterialDesignInXamlToolkit
* **Карти / Геолокація:** GMap.NET

## Основні можливості
* Облік та управління вантажними перевезеннями.
* Реєстрація та Авторизація користувачів.
* Інтерактивна робота з базою даних через Entity Framework Core.
* Зручний та сучасний інтерфейс у стилі Material Design.
* Інтеграція мап для побудови та візуалізації маршрутів (GMap.NET).
